# Roadmap

## P0 — Trustworthy open-source baseline

Licensing, governance, protected releases, repeatable CI, SBOM, signed images, dependency updates, and compatibility documentation.

## P1 — Security and compatibility

Supported bootstrap API, browser session/BFF architecture, generated OpenAPI client, fine-grained server-side RBAC, and strict security headers.

## P2 — Production operations

Production Compose and Helm deployment, observability, backup/restore drills, scalable pagination, audit retention, and WCAG 2.2 AA validation.

## P3 — Enterprise integrations

After the single-organization platform is stable: SCIM, LDAP/AD, SAML federation, conditional access, lifecycle automation, and documented LTS policy.

Roadmap items are directional and do not constitute a delivery commitment.
