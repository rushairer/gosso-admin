# Governance

GOSSO Admin is currently maintained by the repository owner and designated code owners.

- Routine fixes and documentation changes use normal pull-request review.
- Security-sensitive, public API, authentication, deployment, and compatibility changes require a code-owner review.
- Major architectural decisions are recorded as ADRs under `docs/adr/` before implementation.
- Maintainers publish releases, coordinate vulnerability handling, and may revert changes that violate security or compatibility guarantees.

As the maintainer group grows, this document will be expanded with nomination, voting, and conflict-resolution rules.
